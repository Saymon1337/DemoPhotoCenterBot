📌 Реализованный функционал:
Клиентская часть:
Печать фото: выбор форматов (10х15, 15х20, 20х30), гибкая ценовая сетка, автоматическая оптовая скидка (от 100 шт), пакетная загрузка альбомов.
Печать документов: А4/А3, цветная и ч/б печать, прием любых файлов (PDF, офисные документы, сканы).
Запись на фото на документы: сетка тайм-слотов с шагом 30 минут (10:00–19:00 МСК) со строгой валидацией «не ранее 30 минут до визита» и выбором стандарта фото.
Интерактивная корзина: просмотр каждого загруженного файла, поштучная настройка копий [➕]/[➖], индивидуальные комментарии к файлам.
Личный кабинет («Мои записи и заказы»): актуальные статусы заказов в реальном времени и активные записи с возможностью отмены.
Профиль: контакты клиента (имя и телефон) сохраняются при первом заказе и автоматически подставляются в последующих.
Панель управления (Владелец и Персонал):
Разделение прав (RBAC): сотрудники работают только с очередью заказов, Владельцу доступна полная настройка бота.
Живая синхронизация заказов: при взятии заказа в работу карточка мгновенно обновляется у всех сотрудников с указанием ответственного.
Инструменты заказа: скачивание файлов, связь с клиентом в ЛС от имени бота, отклонение с указанием причины.
Сменная аналитика (10:00–19:00 МСК): журнал смены за день, ручной отчет и автоматическая отправка финансовой сводки в 19:00 через фоновый шедулер.
💪 Сильные стороны архитектуры:
No-Code CMS прямо в Telegram: владелец может менять базовые цены, текст приветствия, шапку рассылки и названия кнопок меню без правки кода и перезапуска сервера.
Акции с дедлайном: возможность запустить акционную цену с таймером окончания (например, на 7 дней) — плашка акции автоматически появляется в каталоге и исчезает по окончании срока.
Защита от ограничений Telegram API:
Реализован умный дебаунсер на asyncio.Lock для пакетной загрузки медиа-групп (альбомов) — исключены зависания и спам сообщениями.
Система Alias History для Reply-кнопок: бот распознает старые названия кнопок при их переименовании в CMS и бесшовно обновляет клавиатуру на телефоне клиента.
Чистый модульный код: разделение ответственности (Routers, FSM, Database Queries, Keyboards, Services) на базе современного фреймворка aiogram 3.x.
🔍 Точки роста (компромиссы MVP для масштабирования в Enterprise):
FSM Storage: в рамках MVP использован MemoryStorage. Для продакшна под высокую нагрузку (Highload) переводится на RedisStorage, чтобы сохранять состояния корзины при перезагрузке контейнеров.
База данных: использован асинхронный aiosqlite (идеален для быстрого старта и легкости развертывания). Архитектура запросов вынесена в отдельный слой queries.py, что позволяет бесшовно переключиться на PostgreSQL + SQLAlchemy.
Тип подключения: бот работает на Long Polling для независимости от доменов. Архитектура на роутерах aiogram 3 позволяет переключить его на Webhook + Nginx заменой одной функции.
Платежи: подключение эквайринга (Telegram Payments / ЮKassa) для предоплаты заказов.
